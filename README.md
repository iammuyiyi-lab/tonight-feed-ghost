# 《今夜宜喂鬼》
## iPhone 离线互动绘本游戏 (PWA / Web App)

> 一只饥饿的幽灵在万圣节误入你的手机。它决定先讨一颗糖，再考虑自己究竟为什么来。

---

### 项目亮点与架构
- **平台定位**：iPhone 竖屏 Safari / 添加至主屏幕 Web App，完美适配刘海、灵动岛与底部 Home Indicator。
- **纯离线运行**：PWA Service Worker 本地全量预缓存，**0 外部网络运行时依赖**，脱网 / 飞行模式无缝运行。
- **Web Audio 纯合成音乐音效**：5 支绘本风格背景音乐（暖钢琴、单簧管、小八音盒、温暖罗兹和弦）+ 12 种拟声音效，由 Web Audio API 振荡器与滤波包络实时合成，**0 外部音频文件依赖，体积小于 100KB，加载速度 0ms**。
- **活物级半糖角色**：16 种动作状态机、12 种表情、注视手指追踪、弹性受力形变（戳凹、长按充气、拖晃、滑动翻滚）。
- **全量分镜与分支完整落地**：S00 至 S29 全部分镜 + S30 隐藏心动形态，五大形态独立微游戏真实可玩，12 张文学糖纸、15 个彩蛋、12 首原创怪诗、6 种结局称号、Canvas 高清纪念卡导出。
- **内置 QA 调试面板**：左下角一键呼出 QA 浮层，支持 S00—S30 场景任意直达跳转、全图鉴一键解锁、心动路线模拟。

### 本地快速运行与构建

```bash
# 安装依赖
npm install

# 运行本地开发调试服务
npm run dev

# 运行自动化业务逻辑核验测试
npm test

# 构建生产版本 (输出至 dist/)
npm run build

# 本地预览构建产物
npm run preview
```

### iPhone 部署与收礼人安装说明

1. **部署上线**：
   将 `dist/` 文件夹部署至任意支持 HTTPS 的静态托管服务（例如 GitHub Pages、Cloudflare Pages、Vercel 或任意轻量服务器）。

2. **收礼人首次打开**：
   - 使用 iPhone **Safari 浏览器** 打开该 HTTPS 链接。
   - 看到首屏盖印动画后，点击底部的“分享”图标（带有向上箭头的方框）。
   - 在菜单中选择 **“添加到主屏幕” (Add to Home Screen)**。
   - 桌面即会生成《今夜宜喂鬼》的专属幽灵书本图标。

3. **离线与飞行模式验证**：
   - 首次翻开后，Service Worker 已将所有核心脚本、样式、图标自动缓存在本地。
   - 打开 iPhone 的“飞行模式”，彻底断开 Wi-Fi 和蜂窝网络。
   - 点击桌面图标直接启动，游戏仍可流畅游玩至大结局并导出纪念卡！
